# Madhav-E-commerce-Sales-Dashboard (Interactive Dashboard creation using MS Power BI)

## Project Objective

This PowerBI project provides a comprehensive analysis of sales data, offering valuable insights into sales performance, profit distribution, and customer behaviour across different categories, sub-categories, and payment methods. The dashboard highlights key metrics, trends, and comparisons, making it a powerful tool for strategic decision-making.
